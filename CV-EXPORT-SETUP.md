# CV Export Setup

## Required Dependencies

The CV export feature requires `expo-sharing` package.

### Installation

```bash
npx expo install expo-sharing
```

This will install the correct version compatible with your Expo SDK version.

### Why expo-sharing?

Per requirements: "Hand off to the OS share sheet for saving/sharing"

expo-sharing provides native iOS/Android share sheet integration without custom UI.

---

After installation, run:

```bash
npm run type-check
```

Should show 0 errors.
